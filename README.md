# Character Manager — TP3 (Java Visual SIH-6406)

## Deskripsi
Project ini membangun sistem **Character Manager** berbasis Java dengan prinsip OOP.  
Fitur utama meliputi encapsulation, constructor overloading, enum untuk tipe karakter, validasi data, serta method tambahan seperti `isAlive()` untuk mengecek kondisi karakter.  
Desain ini menjadi fondasi untuk pengembangan GUI dan fitur permainan pada sprint berikutnya.
